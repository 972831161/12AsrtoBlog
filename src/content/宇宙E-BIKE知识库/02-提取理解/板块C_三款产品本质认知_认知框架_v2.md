## 二、Vapor SL · 完整认知图谱

### 2.1 车的灵魂

**程总的一句话：** "全球性能最好的电助力公路车。"

**上车第一感觉：** 以为是普通公路车，然后发现动力大幅强化——踩踏感觉更直接有力，同时完全保留了公路车的运动感和骑行姿势。

**核心体验闭环：**
像公路车 → 比公路车强很多 → 骑得更快更远 → 而不是感觉在"骑电动车"

### 2.2 车架：宇宙的灵魂重量

**999g碳纤维车架** — 这个数字不只是参数，是整车重量策略的起点。

车架决定了电机、电池都必须轻量化——每一个零件都被车架的重量逻辑倒逼。最终整车重量控制在约10kg级别，从根本上实现了"人车合一"的骑行感。

**材料：** 东丽T800/T1000碳纤维，与Pinarello F系列同级供应链。

### 2.3 几何与骑行姿势

**耐力几何（非激进竞技）：**

目标不是UCI竞赛规则下的极限竞技，而是"让普通人骑得爽"。耐力几何让车主可以长时间保持舒适骑行姿势，不是趴着骑，不是僵着骑。

**弯把 vs 平把：**
- 弯把：更气动，更高速，更能压低身体
- 平把：更舒适直立，城市骑行友好
- 同款车架，两种驾驭感，适合不同骑行习惯

**适应周期：**
- 有骑行经验者：瞬间适应
- 纯新手：约1个月/4-5次骑行后完全适应（核心关键：收紧腰腹，姿势正确后几乎无负担）

### 2.4 电机与五档系统

**Bafang M820 PRO（宇宙深度定制版）：**

> "一档就能超过10万的公路车，三档相当于业余顶尖选手水平，五档相当于波加查。"

五档从低到高，助力比例线性上升，核心设计原则是：**人力输入越大 → 助力越大 → 人车合一的感觉越强烈。**

这套系统的意义不是让人"不用骑"，而是让人"骑得更有力量感"。

### 2.5 配置选购逻辑

**车架套件（核心）：** 车架 + 车把 + 电池 + 电机 + 座管 + 牙盘 + 曲柄（自研，利润50%+）

**推荐配置路径：**

| 用户背景 | 推荐配置 | 理由 |
|---------|---------|------|
| 纯新手 | 基础配置 | 足够用，不浪费 |
| 有骑行基础 | UT套件 + DA轮组 | 出货量最大的性价比配置 |
| 速联偏好者 | 速联套件配置 | 保留手感习惯 |
| 追求极致 | 顶配（含618超轻版） | 价格到¥6-7万，一步到位 |

### 2.6 适合谁 / 不适合谁

**非常适合：**
- 想要顶级公路车骑行感的人（有骑行基础的进阶用户）
- 参加业余竞技赛事的骑手
- 追求装备极致、不妥协的人
- 体重偏高但想骑出速度感的用户（电助力让他们找回了自信）

**可能有落差：**
- 完全零骑行基础的新手（需要1个月适应期，期间会有不适应感）
- 期望"越野/探险"的用户（这是公路车的几何，不适合复杂路面）

### 2.7 置换故事（最强情感证明）

**最常说的第一句话：** "Vapor SL真的太好骑了，完美符合我的需求。"

**上海女骑友：** 从跟不上团 → 跟上了 → 成为宇宙推广大使 → 置换后带车去新疆、内蒙古、福建比赛。

**高体重车主群：** 过去100km骑不完 → Vapor SL之后轻松完成 → 甚至可以不开电在队伍里保持速度 → 自信心大幅提升。

**核心情感弧线：** 依依不舍交出旧车 → 拿到新车瞬间被征服 → 骑行版图大幅扩展

### 2.8 618超轻版（极致SKU）

**定位：** 999g裸碳车架，全球最轻电助力公路车架之一，定价¥39,999。

**意义：** 不是给大多数人买的，是宇宙技术实力的旗帜——证明轻量化是可以在电助力车上实现到极致的。

**对整个产品线的价值：** 建立品牌高度，让中低配置的性价比感更强，同时作为内容素材引发关注。

### 2.9 Vapor SL的品牌宣言

> "一步到位，释放你心中的激情。"

## 三、Nomad · 完整认知图谱

### 3.1 车的灵魂

**程总的一句话：** "最适合长途骑行的电助力瓜车。"

**本质状态：** 不是要快、不是要赢，而是要**走得了、走得远、走得自在**。

**和Vapor SL的根本区别：**
- Vapor SL：爆发力，加速感，竞技状态
- Nomad：巡航感，稳健，越走越轻松

### 3.2 核心参数与设计逻辑

**关键参数：**
- 铝合金 + 碳纤维两种车架
- 平把（95%车主选平把）
- 续航 120km（实测，2026-04-23 校正，原 140–150km 作废）
- 胎容：后 45 厘米 / 前 55 厘米（2026-04-23 校正，原"50C"作废）
- 装载孔位：全车 13 个孔位，最满配 7 包系统（2026-04-23 校正）

**为什么用铝合金：**

不是因为省钱。铝合金车架对于Nomad用户来说有一个心理优势——**铝合金让人不心疼**。长途路上碰个石头、停在陌生地方，用户不会因为担心碰到碳纤维而束手束脚。心理自由度 = 骑行自由度。

### 3.3 长途骑行日场景

**城郊日骑：**
均速20-25km/h，骑7-8小时，约150km，中途吃饭充电，充实轻松。

**长途旅行日：**
- 赶路日：200km（两顿饭期间各补电50%）
- 休息日：100km

**续航焦虑：完全不存在。** 120km 续航 + 标准充电桩随处可用，用户甚至不需要带备用电池。

### 3.4 装载方案（13 孔位 / 最满 7 包系统）

**孔位：** 全车共 **13 个装载孔位**（2026-04-23 校正）

| 配置 | 包数 | 位置 |
|------|------|------|
| 最满配 | 7个 | 车把包 + 前叉包×2 + 上管包 + 前三角包 + 货架挎包×2 |
| 座管包版 | 6个 | 前5个 + 座管包（替换货架挎包） |
| 轻量日骑 | 3个 | 座管包 + 前包 + 上梁包 |

**设计哲学：** 13 孔留足、不规定装法，让用户按自己的骑行风格自由组合；7 包是包体数量上限，不是孔位数量上限。

### 3.5 vs 传统旅行车（Surly/Salsa）

**答案只有一句：因为有电助力。**

Nomad是全市场性价比最高的电助力旅行车。电助力是所有传统旅行车无法给予的核心优势。长途骑行中，电助力的价值在上坡时、续航焦虑时、体力不足时全部显现。

### 3.6 价格策略

**程总内部判断：** Nomad可能是宇宙所有产品中**毛利最低**的，战略上期望走大量。

这不是错误，这是设计。Nomad承担着"走量"的使命，毛利低 = 让更多用户进得来。

### 3.7 目标用户画像

**他是谁：**
- 骑之前：可能在骑传统旅行车、城市通勤车、或平路休闲车
- 骑行需求：想去更远的地方，但不想太累、不想太"竞技"
- 生活方式：向往骑行旅行，但有工作家庭，不能全职骑行
- 穿着：愿意穿休闲服骑，不一定穿专业骑行服

**他为什么来看Nomad：**
看到有人骑着Nomad穿越某个地方的内容，心里有了一个地方想去 → 意识到普通车不够用 → 了解到Nomad能帮他做到。

### 3.8 适合谁 / 不适合谁

**非常适合：**
- 想做长途骑行但担心体力不够的人
- 想用自行车去旅行，而不是去比赛的人
- 喜欢在骑行途中携带较多装备的人
- 不想为车"心疼"、想随便骑的人

**可能转向Vapor SL的情况：**
- 越骑越觉得想参加比赛
- 越来越在意速度和竞技感
- 开始觉得Nomad重（约2-3kg差距逐渐有感）

### 3.9 Nomad的品牌宣言

> "我是你探索的好伙伴，一起去你心中想到达的远方。"

## 四、Oi! · 完整认知图谱

### 4.1 车的灵魂

**程总的一句话：**
> "全球最便宜的10kg以内电助力公路车——它可以是一台瓜车，也可以是一台公路车，更可以是一台电助力。买一台车等于买了三台车。"

**定性：** 宇宙多年积累能力的一次集中输出，也是打开骑行市场大门最宽的那把钥匙。

### 4.2 为什么是"全球首创"

Oi!的独特性不在于单个零件，而在于一种组合方式：

```
做改装件的品牌 → 只卖改装件，不卖整车
做公路车的品牌 → 不会搭配电助力改装件一起卖
宇宙 → 同时拥有碳纤维整车能力 + 电助力系统能力 → 做到了两者的整合
```

这个产品只能在中国产生，原因：
1. 国内电助力仍处于导入期，需要"过渡性产品"
2. 宇宙同时具备两种能力
3. 骑行圈的电助力歧视文化仍存在，"可升级"的过渡方案有真实市场需求

### 4.3 性价比的底层逻辑

**核心机制：** 直销基因 → 把代理商和经销商的利润返还给消费者 → 同价位下Oi!比别人更好骑。

**比赛证明：** 女子车手汪星娥，全年预计获得40-50个冠军，击败骑闪电/崔克/Pinarello的对手。

**价格对比：** Oi!整车价格 ≈ 闪电入门款公路车架的价格（1/3到1/5）。

**用户推理逻辑：** 花6,000-9,000元买车架，就能骑出职业赛场验证的竞技能力。

### 4.4 产品形态

**Oi!是一个融合体：**
- 比普通瓜车更气动（有气动造型设计）
- 比普通耐力公路车更结实（更宽的胎宽，更好的滤震）
- 有15个装载孔位（具备一定的装载能力）

**不是单纯的某一品类——是三种车的能力合一。**

### 4.5 均衡版 vs 竞技版

| 版本 | 碳纤维规格 | 核心特点 | 适合人群 |
|------|-----------|---------|---------|
| 竞技版 | T1000/T1100/M46 | 踩踏刚性更强，发力感更直接 | 追求竞技骑行，预算更充足 |
| 均衡版 | T800为主 | 更多装载孔位，更偏长途 | 注重长途实用性，预算有限 |

**实质差别：** 不只是场景，更多是**预算差异**。

### 4.6 解锁三个心理门槛

| 电助力的隐性门槛 | Oi!的解法 |
|----------------|---------|
| 被骑行圈歧视的顾虑 | 它就是一台普通公路车，没有歧视问题 |
| 电助力价格偏高 | 入门价格¥9,999，不需要先花电助力的钱 |
| 售后顾虑 | 普通公路车维护大家更熟悉，没有电系统的额外复杂度 |

**最重要的是"选择权"：** 买了Oi!之后，可以用相对便宜的价格买宇宙电助力轮毂改装件，随时升级。

### 4.7 电助力升级承诺

**用户有多在意：** 非常在意。按目前已下单/购买Oi!的车主反馈，这是大多数人关注和重视的点。

**为什么承诺可信：** 宇宙本身是电助力品牌——用户相信电助力品牌会长期做电助力，不会半途而废。

**营销价值：** 这是Oi!最重要的差异化卖点，是Oi!区别于所有传统公路车品牌的核心——没有其他公路车品牌能给这个承诺。

### 4.8 Oi!电助力轮毂改装件（完整技术图谱）

**产品构成：**
- 带轮毂电机的后轮（替换原车后轮）
- 水壶电池（Type-C充电，可途中换电）
- 一根连接线

**与中置电机（Vapor SL / Nomad方案）的核心差距：**

| 维度 | 轮毂方案（Oi!） | 中置电机（Vapor SL/Nomad） |
|------|--------------|--------------------------|
| 平路加速 | 非常迅猛 | 平顺 |
| 爬坡 | 较差（轮毂天生劣势） | 明显更强 |
| 续航 | 约60-70km | 100km以上 |
| 运动感 | 更强（助力弱→更需人力） | 较弱（推进感强） |
| 安装 | 换后轮（车店¥50-100元） | 出厂整车 |
| Q值 | 和普通公路车一致 | 比普通公路车宽 |

**意外优势（劣势转优势）：** 轮毂电机助力弱 → 更像公路车 → 运动感更强 → 锻炼价值反而更高。

**使用场景判断：**
- ✅ 够用：日常训练、城市骑行、地形平缓
- ❌ 不够：长距离连续爬坡（进藏线等）、需要强劲动力

**安装：** 95%用户需要去车店换后轮，费用¥50-100元。

**上市计划：**
- 正式推出：2026年9月
- 首次展出：2026年5月上海自行车展（带轮毂电机的Oi!整车）
- 销售方式：单独销售 + 和Oi!捆绑销售

### 4.9 目标用户与选购逻辑

**核心目标用户：** 想买专业竞技公路车的新手小白 + 认同宇宙品牌的人

**选Oi!而非闪电/崔克的逻辑链：**
```
认同宇宙品牌/内容/供应链能力
        ↓
发现Oi!性能经过比赛验证
        ↓
Oi!整车价格 ≈ 闪电入门款车架价格
        ↓
性价比极高，理性选择
```

**Oi!的精准用户定位：** 争夺"想进入专业公路车领域但被价格门槛挡在外面"的那批人，不是从闪电铁杆粉手里抢用户。

### 4.10 Oi!升级路径

**触发条件：** 用户接纳了电助力，想要更强性能时自然发生。

**为什么升级容易：** Oi!二手流通简单（公路车整车好卖），退出成本低，升级决策容易。

宇宙会做置换方案来加速这个过程。

### 4.11 宇宙对Oi!的真实判断

**程总总结：**
> "这是宇宙ebike在做了这么久的产品供应链和电助力技术研究之后，积累的能力的一次集中体现。"

**对市场前景的判断：** 有市场空间，非常有前景，但是否成功有待验证（首批交付质量是最大风险点）。

**宇宙的破圈态度：** 不在意骑行圈的反应，目标是让圈外对骑行感兴趣的人看到宇宙、选择宇宙。对骑行圈的最低预期：圈内人能认可性能、认可Oi!合理 → 宇宙就满意了。

### 4.12 Oi!的品牌宣言

> "我给你保留了解锁电助力的可能性，一起打开这扇门。"

## 五、三款车的选购决策体系

### 5.1 三问选车法

遇到新用户，程总的三个核心问题：
1. **基本情况？**（性别、年龄、体重）
2. **想怎么骑车？**（休闲 / 竞技 / 长途）
3. **带电还是不带电？**（Oi!时代新增的关键问题）

### 5.2 犹豫 Vapor SL vs Nomad 时的拍板逻辑

**问题背景：** 预算卡在1.7万-3万之间，两款都买得起但都有压力。

**关键不是性能对比，而是问自己：**
> "我想要一台非常酷炫的竞技车，还是想要一台融入日常生活的旅行车？"

价格差一倍 = 20-30%的性能提升 — 这在竞技产品里是正常溢价逻辑，理性用户能接受。

### 5.3 销量预测与产品分工

**销量排序预测：** Nomad > Oi! > Vapor SL

**三者分工：**

| 车型 | 战略使命 |
|------|---------|
| Oi! | 拓宽漏斗，触达最多用户，降低进入门槛 |
| Nomad | 跑量，覆盖主流骑行人群，毛利最低走量最大 |
| Vapor SL | 建立品牌高度，最高性能，最强品牌声量 |

### 6.1 产品结构哲学

**程总的视角（极有价值）：**

这是系统思维：不追求单品爆款，追求产品线生态健康。

### 6.3 宇宙产品线总结

> 不追求单品爆款，追求产品结构的整体健康。用Oi!拓宽漏斗，用Nomad跑量，用Vapor SL建立品牌高度。三者协同，覆盖中高端骑行市场的全价位段。

## 九、售后与维修体系（C52-C53）

### 9.1 用户报修路径

```
发现问题 → 联系销售专员 → 判断是否在保
    ↓
├─ 当地车店能处理 → 就近解决（宇宙协助联系）
├─ 需寄修零件 → 拆下电机/电池/仪表邮寄回公司
└─ 复杂问题 → 整车寄回全面排查
    ↓
到货第一时间处理 → 最慢约一周修好寄回
```

**全国一致性：** 一线到三线城市处理路径无差异，全国均可联系当地车店配合。

**备件储备：** 极其充足，可牺牲现有库存优先保障售后。

### 9.2 售后短板（程总坦诚）

- **最大短板：** 线上沟通效率低于当面，部分用户难以沟通
- **现状：** 目前没有出现过解决不了的问题，团队以极高热情和专业度服务
- **无解情况：** 恶意讹钱用户 → 只能认赔退款召回。这是直销模式的成本

## 十、特殊条件骑行（C54-C55）

### 10.1 防水能力

**防水等级：** IPX6（部分款式实际达到IPX7，对外统一标注IPX6）

| 场景 | 建议 |
|------|------|
| 一般涉水、小雨 | ✅ 完全没问题 |
| 大雨中骑行 | ⚠️ 不推荐（电系统风险 + 金属零件锈蚀） |
| 涉水后立即充电 | ❌ 严禁（先关好充电口保护罩） |

**行业通则：** 公路车雨天骑行后需洗车保养，宇宙同理。

### 10.2 低温性能

| 温度 | 续航影响 | 备注 |
|------|---------|------|
| 0°C以上 | 基本无 | 正常使用 |
| -5°C左右 | <10% | 无异常 |
| -20°C | 影响不大 | 可能短暂充电困难/电池休眠 |

**实测：** 宇宙曾在-20°C环境骑长途，未感受到续航显著衰减。北方用户冬天完全可以正常骑。

**不在保范围：** 正常磨损 / 人为损坏 / 自然灾害 / 未经授权维修 / 不当存储

### 11.2 报修申请流程

1. 通过客服/授权门店提交质保申请（需购买凭证+故障描述+照片视频）
2. 技术团队检测评估，判断是否在保
3. 在保→免费维修或更换；不在保→提供维修建议和费用报价
4. 到货发现的工艺缺陷：宇宙承担全部物流和维修费用

### 11.3 "如果宇宙倒闭了"

程总原话：

> "我们会存够足够的零件，车主可以直接联系到我来辅助售后。可能会寄托于八方或其他合作伙伴来进行更换和质保。当我们倒闭时，90%的车主应该已经过了质保期了。只要能联系上核心同事，都会给相关建议。"

**用户安全感来源：** 创始人个人兜底承诺 + 八方（Bafang）作为全球最大电机厂长期存在 = 零件供应不会彻底断绝。

## 十二、M820 Pro 电机技术详解

> 来源：八方官方升级说明文件（2025年6月）+ 程总补充说明

### 12.1 升级全貌

| 升级方向 | 旧版M820 | 新版M820 Pro |
|---------|---------|------------|
| 力矩传感器精度 | 48信号/7.5°精度 | 72信号/5°精度 |
| 霍尔传感器 | 1个 | 2个 |
| 磁钢数量 | 1个 | 2个 |
| 齿盘 | 24T | 36T |
| 控制器来源 | 外购 | 宇宙自研 |
| 出线方式 | 接插式 | 甩线式 |
| 防水等级 | — | IPX6 |
| 散热/寿命 | 标准 | 显著提升 |

### 12.2 力矩升级的骑行意义

踏频测量精度从7.5°→5°，意味着：
- 微小踏频变化也能被精确捕捉
- 启停响应时间大幅缩短，感觉更灵敏
- 频繁启停场景（城市、坡道）体验显著改善
- "人车合一"感觉进一步增强——力输入更小就能触发更准确的响应

### 12.3 自研电控的战略意义

**技术层面：** 效率提升 → 同等电池容量下可调用更强输出，不牺牲续航。

**战略层面：** 宇宙对电机特性拥有完全掌控权——可针对不同骑行场景（城市/爬坡/竞技）深度调校助力曲线，且可通过固件OTA持续迭代优化。

**销售层面：** 这是宇宙和其他使用M820旧版电机品牌的根本差异之一——相同电机，宇宙的调校不同，体验不同。

### 12.4 核心认知总结

> M820 Pro不只是一个供应商的零件升级，它是宇宙对电机技术掌控深度的体现。自研电控意味着未来的体验迭代不再依赖八方，宇宙可以自主定义骑行感。
