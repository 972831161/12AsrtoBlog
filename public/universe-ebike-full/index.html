UNIVERSE E-BIKE // 2021-2025

从零起步
做制造业
真的太难了

三年前，我开始造自行车，到现在已经烧掉了两千多万。
这是在悬崖边缘的求生记录。

01 // ORIGIN
烧掉两千万，只为那台梦幻机器

为了造出真正的电助力公路车，我们投入了千万级的研发成本。欧美大牌卖十几万的产品，我们只卖两万多。

有了它，你可以和我一样，骑着车去珠峰大本营，穿越新疆大海道和羌塘无人区。我在无人区骑了 20,000 公里，只为验证它的韧性。

02 // ILLUSION
繁华背后的错觉：漫长的等待

2020年，欧洲电助力自行车销量突破 500 万辆，渗透率 23%。这个数字让投资人兴奋。大家以为国内市场能复制欧美的增长曲线，但等待的过程却格外漫长。

03 // CRISIS
黄金赛道，突然熄火

宇宙电动成立于 2021 年底。半年后情况急转直下：德国、荷兰等市场销量断崖式下跌。这个翻了十倍的黄金赛道，突然熄火了。

上市公司财报里刺眼的数字——营收腰斩、利润下滑 80%。据统计，22 年来超 1000 家骑行品牌申请破产保护。

04 // BARRIERS

无法逃脱的“宿命”

欧美壁垒：禁止在中国组装整车，限制核心部件。美国 45%、欧洲 70% 的歧视性关税，让品牌和消费者都难以承受。只要企业实控人是中国人，就逃不开被欧美压制的宿命。

05 // PIVOT
调转枪口：回主场大干一场

那年，我烧掉了第一个 1000 万。为了赢得信任，我亲自带队在西藏测车。首批 300 台在国内迅速售罄。

我逐渐想明白：行业周期性回暖也无法改变政策歧视，我们需要扎根自己的主场。所以，我们决定在国内市场大干一场。

06 // RESTART
老船厂里的孤独与当头一棒

2023 年初，我们在杭州运河边租下了一间老船厂。但现实给了我当头一棒：资本市场完全停滞。在大疆进入行业前，多数基金将电助力归类为前途未卜的新领域。

「做一个全新的领域很孤独，我没有可参考的路径。每一个商业决策都需要独立判断。」
07 // TRANSFORMATION
战略转型：一站式解决方案

我们将线下空间从单一展厅升级为“一站式骑行解决方案服务商”：代理优质品牌，系统性投入文化培育。

这一步让我们从被动式获客转向主动的内容营销，打通了整车、装备、服务全链路。

08 // THE WALL
为什么拒绝“低价车型”？

2000 元电瓶车垄断了实用主义，任何性价比 E-BIKE 在它面前都显得苍白。我相信没人会“爱”自己的电瓶车。用户真正需要的不是强行灌输的销售话术，而是一个能让他们完整感受产品的空间。

09 // DECISION
砍掉 9999 元的产品：拒绝平庸

2022 年秋天，离推出 9999 元车型只差一步，我决定不卖了。白做了就白做了。

理由很简单：这类产品牺牲了核心骑行体验。如果一开始就觉得别扭的产品，最终一定是错的。 最终，同质化的辅助轮毂产品在内卷中逐渐消失。
