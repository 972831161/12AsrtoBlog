# 宇宙 E-Bike (Planet Between) 官方应用 PRD 及实现计划

## 1. 竞品调研与市场分析
为打造符合高端、科技、探索定位的 E-Bike 骑行应用，我对市面主流的骑行类应用进行了横向调研：

| 竞品 / 类型 | 核心优势 | 劣势 / 对我们的启示 |
| :--- | :--- | :--- |
| **行者 / 黑鸟单车** | 纯粹的骑行工具，路书生态完善，硬核用户基盘大 | 缺乏针对特定品牌 E-Bike 的深度硬件联动，UI 设计偏传统硬核，缺乏高端生活方式感。 |
| **Specialized (Mission Control)** | 电机微调（Smart Control）功能强大，可根据路线自动分配电量 | 社区属性弱，仅作为硬件控制工具，用户粘性通常只在骑行中。 |
| **Bosch eBike Flow** | 深度的单车防盗、导航、健康数据整合，OTA 升级 | 偏向通勤和专业骑行，缺乏趣味性和社交互动性。 |
| **Strava** | 极致的社交排行榜（路段赛段）系统 | 面向硬核运动用户，且国内网络连接体验较差。 |
| **小红书 / 贴吧** | 极强的图文种草属性和生活方式分享交流 | 无法与车辆真实数据打通，无法权威呈现专业的路线和路书。 |

**得出结论**：
我们的产品不应仅仅是一个“仪表盘”，而应该是一个兼具**“车辆智能控制、探险生活方式展示、LBS地理社交”**的数字触点。我们需要结合 Specialized 的**硬件控制**、行者的**专业路书**、小红书的**图文分享**，并且独创性地融入基于 LBS（基于位置服务）的 **AR 探索玩法**，精准切中年轻、潮流骑士的探索欲和成就感。

## 2. 核心功能规划 (Feature Map)

小程序暂定代号：**Planet Between (宇宙骑行)**

### 2.1 🔋 车辆互联与基础中控 (Device & Dashboard)
- **极速绑定**：通过扫码车架二维码或蓝牙广播一键绑定“宇宙自行车”。
- **车辆状态大屏**：
  - 剩余电量（百分比直观展示）。
  - **精准预估续航**：结合当前骑行者的踏频习惯和所选助力档位，动态计算剩余里程。
  - 车辆在线定位（防盗基石）。
  - 电子固件自检报告（电机、电池健康度）。
- **骑行仪表盘**：全屏高对比度实时呈现：速度、骑行时间、当前踏板助力比、日落/天气恶劣预警提示。
- **智能电子锁**：一键落锁/解锁电机，车辆在设防状态下的异动侦测并实时推送到微信。

### 2.2 🚴‍♂️ 骑行数据与成就体系 (Ride & Stats)
- **极验实时轨迹**：基于微信小程序位置服务提取 GPS，静默录制运动轨迹，支持后台保活。
- **历史时光机**：内嵌按 年/月/日 检索的骑行历史抽屉，搭载类似 GitHub 的“**日历热力图**”，让天天骑行成为一种视觉养成。
- **生涯统计碑**：累计骑行总里程、爬升总海拔、碳减排环保换算、途径/点亮过多少座城市地图。

### 2.3 🌍 “宇宙坐标” - 核心彩蛋与探索玩法 (AR Easter Eggs)
*这是本应用拉开与其他单纯仪表的独占杀手锏，结合了《Pokemon Go》盲盒与地理寻宝（Geocaching）的浪漫。*
* **打点留言 (AR Drop)**：用户在旅途风景绝佳处，或具有特殊意义的打卡点，可下发一个“虚拟坐标舱”。在这个舱内，用户可以留下想说的一段话、一张 360 度全景模型，或是环境 AR 录像。
* **雷达探测器**：当其他宇宙骑士骑行至坐标设定半径内（如 500 米内），微信/仪表盘发出提示：“雷达范围内发现其他骑士留下的宇宙能量舱”。
* **实景寻宝 (AR)**：用户可在雷达中选择【前往揭秘】，到达坐标点后，手机调用微信 AR 相机扫描实景，寻找悬浮空中的 AR 箱子，点开获取内容与前人的寄语。并且可以基于此打卡留名。
* **彩蛋与成就收集强**：例如“点亮收集北京中轴线上的全部官方能量舱”，可获得限量版实体骑行服，或应用内专属高阶称号。

### 2.4 🗺️ 社区与路书大厅 (Community & Routes)
- **探索信息流 (类似贴吧/小红书)**：分享的图文内容天然可以绑定该次骑行的路线图层（包括速度、海拔波动曲线等硬核数据背书）。
- **路书共创大厅**：官方、本地车店或资深达人上传精选骑行路线（提供避坑指南、途中最佳风景点、补给站发夹弯提醒）。
- **离线路书指引**：考虑到长途/山区骑行可能遇到的无网络情况，依仗路书预下载内容开启 GPS 脱网导航（需配合地图原生组件能力）。

### 2.5 🛠️ 用户体系与售后支援 (Service)
- **一键维修与专属客服**：基于微信生态的即时在线沟通与留言反馈。
- **服务网点地图**：宇宙官方体验中心（销售点）及授权维修/咖啡服务站（支持一键导航直达）。
- **电子说明书与 FAQ 视频百科**：如何调节避震拉力、如何日常清洗链条等图文/短视频保养指南。

## 3. 开发架构与工程说明
经确认，本项目采用 **Uni-app** (Vue3 + Vite) 技术栈进行开发，初期着眼于一套代码多端运行，为主打的微信小程序端提供坚实基础，并为未来零成本封装为 iOS/Android 独立 App 预留能力。

开发节奏上，项目将分为两部分进行迭代替代：
- **一期 MVP**：跑通小程序仪表盘、设备状态（基于前端 Mock 数据）、历史骑行大图、维修导航。
- **二期 进阶模块**：实装基于 LBS/AR 的宇宙坐标舱社区与路书大厅双摄流。
